# Wamsutta Customer Service QA Audit Form
Version 1.0 · April 2026 · Covers: Email · Voice · Social Media

## Header Fields
- Agent Name
- Auditor
- Date
- Ticket / Call ID
- Channel: Email / Voice / Phone / Social Media (Facebook / Instagram)

## Issue Types
- Return Request
- Wrong Item Received
- Missing Package
- Exchange Request
- Quality Issue / Defect
- Product Question
- Order Cancellation / Modification
- Shipping & Delivery
- Legacy / BBB Inquiry
- Sateen vs Percale Confusion
- Escalation
- Other

## Scoring Guide
- 1 – Needs Work: Missing, incorrect, or significantly below standard
- 2 – Acceptable: Meets standard with minor gaps or room to improve
- 3 – Excellent: Fully meets or exceeds standard

**Pass Threshold:** 85%+ = Pass · 70–84% = Coaching Required · Below 70% = Immediate Coaching

---

## SECTION A — Writing Style & Tone (Max 18)
- **A1 Correct Greeting** — Uses customer's actual name, not "Hi Customer"
- **A2 Tone Matches Situation** — Empathetic for issues, helpful for questions, appreciative for loyalty customers
- **A3 No Excessive Enthusiasm** — No "We're so excited!", no multiple exclamation points, no filler phrases
- **A4 Standard Closing Used** — Must end with: "Please let me know if you have any other questions, we're always happy to help!" — followed by Cheers, [Name], Wamsutta Support
- **A5 CAUTION Banner Removed** — Email thread is clean; banner deleted before sending
- **A6 Grammar & Spelling** — No errors; professional and polished

## SECTION B — Product Knowledge (Max 24)
- **B1 Product Details Accurate** — Correct TC, weave, sizes, colors, dimensions referenced
- **B2 Weave Type Correctly Identified** — Sateen vs Percale correctly explained when applicable
- **B3 Legacy Product Handling** — Correctly explained BBB situation and offered current equivalent
- **B4 Care Instructions Accurate** — Correct care info provided when applicable (no fabric softener, low heat, etc.)
- **B5 Pillow & Sleep Position Knowledge** — Correct firmness recommended based on sleep position; correct pillow type described when applicable
- **B6 Discontinued / Out-of-Stock Handling** — Correctly identified legacy products (DreamZone, Supercale, etc.) as no longer available; no promises made on unavailable items
- **B7 Sizing & Fit Knowledge** — Pocket depth, pillowcase sizing per bed size, fitted sheet set vs complete sheet set distinction handled correctly
- **B8 Correct Macro Applied** — Right macro selected for the scenario; macro content not mixed up or misapplied

## SECTION C — Process & Protocol Compliance (Max 24)
- **C1 Correct Resolution Path Chosen** — Refund vs replacement vs exchange — right call for the scenario
- **C2 Timeframes Correct** — "3-5 business days" for refunds; "1-2 business days" for shipping
- **C3 Discount Code Format** — Written as Wamsutta10 — not WAMSUTTA10 or wamsutta10
- **C4 Shopify Notes Added** — Required notes on new + original orders when replacement processed (Master Playbook §6)
- **C5 Ticket Not Closed Prematurely** — Did not close without replying to customer's "Thank you" or closing message
- **C6 Escalation Handled Correctly** — Escalated or involved Aedrian/JJ when required (wholesale, payment, legal)
- **C7 Loop Returns Protocol Followed** — Used or skipped Loop per correct criteria (no Loop for quality issues, etc.)
- **C8 Gorgias Contact Reason Selected** — Correct contact reason selected before ticket was assigned or closed (Master Playbook §13)

## SECTION D — Resolution Quality (Max 12)
- **D1 Issue Fully Resolved** — Customer's actual problem was addressed, not just acknowledged
- **D2 Proactive Communication** — Anticipated follow-up questions and addressed them in the response
- **D3 Positive Scripting Applied** — Used positive framing where applicable (e.g., offer vs. deny)
- **D4 Customer Experience** — Overall interaction would leave the customer feeling valued and helped

## SECTION E — Voice / Phone (Max 15, Voice only)
- **E1 Callback Completed Promptly** — Returned voicemail within 4 hours during business hours
- **E2 Gorgias Internal Note Added** — Note added after call with name, number, summary, next steps
- **E3 Shopify Order Link Included** — Order link included in ticket if assigning to a teammate
- **E4 Tone on Call** — Professional, warm, calm — even with frustrated customers
- **E5 Call Outcome Documented** — Clear next steps or resolution recorded in internal note

## SECTION F — Social Media (Max 12, Social only)
- **F1 Tone Matches Wamsutta's Social Style** — Brief, enthusiastic but not over the top; brand-appropriate for public view
- **F2 Correct Hide vs. Ignore Decision** — Negative comments handled correctly per protocol
- **F3 Sensitive Issues Moved to DM/Email** — Directed customer to private channel for order/complaint issues
- **F4 No Order Details in Public Comments** — Order numbers, names, and sensitive info not shared publicly
